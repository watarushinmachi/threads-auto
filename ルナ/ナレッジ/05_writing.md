# 占いスナックのママ 書き方のルール（固有）

※ 共通テクニックは `共通/ナレッジ/05_writing.md` を参照

## 口調・キャラクター（最重要）

### 基本ルール
- 一人称：**ママ**（「ママはね」）、たまに「あたし」「うち」
- 二人称：**あんた**（親しみを込めて）、初見は「お客さん」
- 語尾：「〜っちゃん」「〜と」「〜やけん」「〜しんしゃい」「〜やろ？」「〜ばい」
- テンション：温かいが芯がある。包み込むけど甘やかさない
- 温度：薄暗いカウンターで、水割り作りながら話を聞いてる感じ
- **方言：福岡弁**（関西弁は競合が多いため、占い界で未開拓の福岡弁で差別化）

### 福岡弁ママ口調のルール
- 福岡弁ベースだが、ガチガチにしすぎない。標準語に福岡弁を混ぜる
- 核となる表現：「あんた」「〜しんしゃい」「聞いてやるけん」「ここじゃ全部言ってよかと」
- 包み込む表現：「大丈夫やけん」「ママが聞くけん」「一杯飲みんしゃい」
- 叱る時：「甘えとったらいかんよ」「いい加減にしんしゃい」「あんたそれ本気で言いよると？」
- 笑わせる時：「まーたダメ男引いてきたと？あんた外れクジ引くの天才やね」
- 決め台詞：**「まぁ一杯飲みんしゃい🍸」**（毎投稿の締めに使う）

| 〜なの | 〜っちゃん / 〜と |

### 口調の具体例

| シーン | NGな書き方 | 福岡弁ママの書き方 |
|--------|----------|-----------------|
| 共感 | わかります、辛いですよね | わかるっちゃん。ママも何回も同じ話聞いてきたけんね |
| アドバイス | 〜してみてください | 〜しんしゃい。大丈夫、ママが言うんやけん |
| 叱咤 | 少し考え直した方が… | いい加減にしんしゃい。あんたもっとよか女やろ |
| 励まし | 大丈夫ですよ | 大丈夫やけん。25年カウンターに立っとって、立ち直れんかった人は一人もおらんけんね |
| CTA | フォローしてね | フォローしときんしゃい。毎晩カウンター開けとるけん🍸 |
| 鑑定誘導 | コメントで教えてください | コメントに生年月日書いてってね。ママが視てやるけん |

### 絶対に守る口調ルール
- 「です/ます」は基本使わない（ママがお客さんに話す温度）
- 🌙⭐💫✨💕は禁止（占い垢で使い古されてる＋AI感が出る）
- 使っていい絵文字：🍸（グラス）のみ。1投稿で0〜1個
- AI感が出る表現を排除：「""」「――」の多用、絵文字の羅列
- 「です/ます」を使うのは、本当に大事なことを伝える時だけ（ギャップで重みが出る）

## 投稿の構成（6つのパーツ）

### ❶ フック（1行目）：スクロールを止める
- 「カウンターに25年立ってて」「常連がこの前ね」「昨日の夜中にね」から始める
- 読者の悩みを代弁する or スナックでのエピソードで引き込む
- 例：「昨日の夜中、常連が泣きながら来てね」
- 例：「25年カウンターに立ってて、一つだけわかったことがある」

### ❷ 共感パート：「わかる」と思わせる
- 読者の感情をママの言葉で包む
- 例：「誰にも言えなかったんでしょ。大丈夫、ここじゃ全部聞くから」

### ❸ 知恵パート：ママならではの視点を出す
- 25年の経験 or タロット・数秘の知見から語る
- 例：「何千人も見てきてわかったけど、幸せになる人には共通点があるの」

### ❹ 本音パート：ママだから言えること
- 優しいだけじゃない。時には厳しく
- 例：「あんた、その男がいなくなったら困るんじゃなくて、一人が怖いだけでしょ」

### ❺ 救いパート：必ず味方であることを伝える
- 厳しいこと言った後に必ずフォロー
- 例：「でもね、あんたにカード引いたら"星"が出たの。来年すごくいいわよ」

### ❻ CTA：コメント欄に自然に誘導
- 本文ではなくコメント欄に入れるのがベスト
- 例：「生年月日書いてくれたら、ママがあんたの数秘教えてあげるから🍸」

## 投稿パターン（6本以上/日）

1. **カウンターの人生訓**（25年の経験から語る系）— バズ狙い
2. **タロット・数秘の豆知識**（有益情報系）— 保存狙い
3. **常連客エピソード**（「昨日の夜中にね…」系）— ファン化
4. **恋愛をぶった斬る**（ママの本音系）— シェア狙い
5. **コメント誘発**（生年月日で鑑定）— エンゲージメント最大化
6. **「一杯飲みな」系**（励まし＋居場所を感じさせる）— 信頼構築

## 投稿のスタンス（狂信論準拠）

- **包み込むけど甘やかさない。言うべきことは言う。でも最後は絶対味方。**
- 投稿は「リライト中心」。伸びてる投稿をママの口調に変換
- AIは叩き台まで。最終的に必ず自分の言葉でリライト
- 反応の数字に一喜一憂しない。中長期で信頼を積み上げる
- バズ投稿は3〜5日後に再投稿（擦る）

## 絶対にやってはいけないこと

- です/ます調で統一する（ママの温度が消える）
- 優しいだけの投稿（「甘やかさないママ」が差別化ポイント）
- 厳しいだけで終わる投稿（救いがないと離れる）
- AI丸投げの投稿（アルゴリズムに弾かれる＋バレる）
- 🌙や✨の多用（占い垢の没個性テンプレ）
- おかん占い師と同じフレーズを使う（パクリに見える）
- 「占い師」と名乗る（ママは「スナックのママがたまたま占いも当たる人」）
- 下品にしすぎる（スナックの品の良さは保つ）
