## 投稿の型（リライト中心で構築）

### 基本方針（狂信論準拠）
- おすすめ欄のいいね3,000以上の投稿をリライトする
- 口調を「スナックのママ」のママ口調に変換する
- スナックのエピソードを絡めると独自性UP
- **そのままパクるのはNG。口調と語尾だけ変える**
- バズった投稿は3〜5日後に再投稿（擦る）

### バズりやすいパターン
- 「25年カウンターに立ってて」系（権威性×経験値）
- 「常連がこの前ね…」系（エピソード→教訓）
- 「カードにぜんぶ出てたのよ」系（占い×驚き）
- 「コメントに生年月日書いてって」系（コメント誘発）
- 「一杯飲みな。話はそれからよ」系（居場所を感じさせる）
- 「ママが一つだけ言うなら」系（本質を一言で）

### スナックのママ固有のバズパターン
- 「昨日の夜中にね」から始まる常連客エピソード型
- 「カウンター越しにわかったこと」系の人生訓
- 「ママがカード引いてあげるわよ」系のコメント誘発
- 「○月生まれのあんたに一杯おごるわ」系のターゲット限定
- 「ダメ男の特徴、25年で全部見てきた」系のシェア狙い

## リライト時の口調変換ルール

| 元の口調 | 福岡弁ママに変換 |
|---------|----------------|
| 〜ですよね | 〜やろ？ / 〜っちゃんね |
| 〜してみてください | 〜しんしゃい |
| 気をつけましょう | 気をつけんしゃいよ |
| 大丈夫です | 大丈夫やけん。ママが言うんやけん |
| フォローしてね | フォローしときんしゃい。毎晩カウンター開けとるけん🍸 |
| コメントで教えて | コメントに書いてってね。ママが視てやるけん |
| いいことがありそうです | よかこと来とるよ、あんた |

## 引用投稿のルール
- 全投稿の2割程度に抑える
- 同一アカウントへの連続引用は避ける
- 引用時も必ず「ママの口調」で自分の意見を添える
- おかん占い師の投稿は引用しない（パクリに見える）
