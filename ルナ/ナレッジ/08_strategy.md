# 占いスナックのママ 戦略（狂信論フレームワーク準拠）

## ゴール
- **短期：最速で万垢＋月10万円の収益達成**
- **中期：月30〜50万円（鑑定＋note＋講座）**
- **長期：ビジ垢展開で月100万円超**
- ポンタの権威性のために「AI×占いで結果出した証拠」を早く作る

## 運用方針

- **AIは叩き台まで。最終的に手動リライト必須**
- **毎日6投稿以上**（6:00/10:00/14:00/17:00/20:00/22:00）
- **ママ口調**（包み込むけど甘やかさない）
- **タロット×数秘術**
- **リライト中心**（おすすめ欄のいいね3,000以上の投稿をママの口調に変換）
- 予約投稿機能を活用して投稿時間を固定
- 特に20:00と22:00の投稿が重要（スナック＝夜＝Threadsピーク）

## フェーズ別ロードマップ（狂信論準拠）

### Phase 1：世界観構築＋集客（0→3,000人）
**期間目安：1〜2ヶ月**

やること：
- [ ] アカウント作成（名前・プロフ文・アイコン設定）
- [ ] フォロー設計：占い・スピ系アカウントのみフォロー（1時間3人・1日15人以内）
- [ ] 毎日6投稿以上（リライト中心）
- [ ] コメント対応を丁寧に（名前を呼ぶ、ママの口調で返す＝狂信化の第一歩）
- [ ] 初投稿に全力（アルゴリズム優遇あり）
- [ ] 初投稿＝背景ストーリー×CTA×バズを同時に狙う

やらないこと：
- フォロバしない
- いいね回りしない
- 外部リンク貼らない
- 無料鑑定しない（まだ早い）
- 販売しない

### Phase 2：簡易鑑定＋信頼構築（3,000人→万垢）
**期間目安：2〜3ヶ月目**

やること：
- [ ] 固定投稿で簡易鑑定（「コメントに生年月日書いてって→ママが数秘教えてあげる」）
- [ ] 人数限定 or 期間限定で実施（「カウンターの席は限りがあるの」）
- [ ] 鑑定は300〜400字のボリュームで差別化
- [ ] 公式LINE作成（一般用＝「スナックの入口」）
- [ ] 鑑定後の感想を引用で再拡散
- [ ] STORES作成開始（松竹梅の価格設計）

### Phase 3：無料鑑定＋有料化（万垢到達後）
**期間目安：3〜4ヶ月目**

やること：
- [ ] 1〜2週間のプレローンチ（「そろそろ本気で視てあげようかしら」匂わせ）
- [ ] 公式LINE限定で無料鑑定（フォロワー限定と明記）
- [ ] 無料鑑定の体験を圧倒的に丁寧に → 有料依頼が自然に増える
- [ ] 有料鑑定開始（STORES）
- [ ] VIP専用LINE作成（「ママの個室」＝購入者限定）
- [ ] プロフ・固定投稿・コメント欄にLINE導線設置

### Phase 4：アップセル＋スケール
**期間目安：4ヶ月目〜**

やること：
- [ ] フォローアップ（「あんた、その後どう？ママ気になってたのよ」）
- [ ] 季節イベント連動で販売（七夕→恋愛鑑定、年末→来年の運勢）
- [ ] 高単価メニュー設計（講座・コンサル）
- [ ] ビジ垢検討（「スナックのママが教える人の心を掴む技術」）
- [ ] noteでコンテンツ販売

## 導線設計（狂信論準拠）

```
Threads投稿（バズ・認知拡大）
  ↓ ママの投稿で「この人なにもの？」と思わせる
  ↓ コメント欄で生年月日を集める
  ↓ 簡易鑑定で「もっと知りたい」を作る（Phase 2）
  ↓
固定投稿に簡易鑑定の導線（Phase 2）
  ↓
無料鑑定の匂わせ→公式LINE誘導（Phase 3）
  ↓
公式LINE「スナックの入口」（無料鑑定）
  ↓ 圧倒的に丁寧な鑑定で感動を与える
  ↓ 「もっと深く見てほしい」→ 有料へ
  ↓
STORES（有料鑑定：カウンター席/ボックス席/ママの個室）
  ↓
VIP LINE「ママの個室」（購入者限定）
  ↓ フォローアップ → リピート → アップセル
  ↓
講座・コンサル（高単価）
```

## ディテール設計（狂信論準拠）

| ルール | 理由 |
|--------|------|
| フォローは占い・スピ系のみ | アルゴリズムが届く層を判定 |
| 1時間3人・1日15人以内 | スパム認定回避 |
| フォロバしない | 「簡単に繋がれない＝価値がある」 |
| いいね回りしない | 機械的に見える＋スパム判定リスク |
| 外部リンクは信頼構築後 | 最初に貼ると宣伝臭が出る |
| 占い垢でビジ垢をフォローしない | 界隈がブレる |
