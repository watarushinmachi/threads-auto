# 占いスナックのママ ジャンル設計

## メインジャンル
**人生相談 × タロット × 数秘術（カウンター越しの運命鑑定）**

## サブジャンル
- 恋愛・夫婦関係（課金率最強テーマ）
- 仕事・転職・人間関係
- 子育て・家族
- 「一杯飲みながら聞いて」系の人生訓

## なぜこのジャンルか（リサーチ根拠）

### 「スナックのママ × 占い」の優位性
- おかん占い師（9.6万）が証明した「生活×占い」モデルの発展型
- ただしスナック＝夜＝Threadsのゴールデンタイム（20-22時）と完全合致
- 「何千人の話を聞いてきた」が占い師としての信頼を自然に担保
- タロットは個別鑑定との相性最強（カード名だけでドラマが成立、テキストベースのThreadsと完全合致）
- 数秘術は生年月日だけで鑑定 → コメント欄の簡易鑑定と相性◎
- スナック＝恋愛も仕事も人生もすべて話せる場所 → ジャンル制限なし

### 競合との差別化
| 競合の多数派 | 占いスナックのママ |
|------------|-----------------|
| です/ます丁寧語（47%） | ママ口調（「あんた」「〜よ」「〜なさいよ」） |
| 霊視（多数） | タロット×数秘術（スナックのカウンターで引く） |
| 占い師ポジション | 「スナックのママがたまたま占いも当たる」 |
| 昼の世界観 | **夜のカウンター（Threadsと合致）** |
| 恋愛特化 or 全方位 | 全方位だが恋愛が自然に多くなる |

### Threadsとスナックの相性が異常に良い理由
1. **時間帯**：Threadsのピーク＝20-22時＝スナックの営業時間
2. **テキストベース**：スナック＝会話の場所＝Threadsのテキスト文化と合致
3. **匿名性**：スナック＝名前を名乗らなくてもいい＝Threadsの匿名性と合致
4. **距離感**：カウンター越し＝近すぎず遠すぎない＝フォロワーとの理想的な距離
