# ポンタ 戦略

## 発信上の旗印（near-term）
- **「副業初心者が物販で"まず月1万円"にたどり着くドキュメンタリー」**
- 「人生逆転」「月30万」は言わない。小さく刻んで応援される
- ストーリー（探す→停滞→出会う→稼ぐ）の進行そのものがコンテンツ（→ `09_story-arc.md`）

## マネタイズ
- 出口：**楽得物販**（利益情報配信オンラインサロン／アフィリ商材）
  - 料金：初月無料・2ヶ月目以降 月額20,000円／想定利益 月6〜10万円
  - 訴求の核：**サポート担当が1人つく**（初心者の最大の不安＝続かない/相談できないを解消）／具体的な仕入れ先・販売先が配信される／お得情報・ポイ活も
  - リンク：https://youtu.be/YJZGFFqiNgo（※本文に貼らずプロフ誘導）
- ストーリーの「転機（副業14日目に楽得物販に出会う）」がそのまま商品紹介の自然な文脈
- 誇大NG：「絶対月6万」ではなく「想定はそう、自分はまず月1万」と等身大で

## ファネル（ドキュメンタリー型）
```
フェーズ1-2（探索・停滞）：共感を集めてフォロワー化（"自分と同じ人"）
   ↓
フェーズ3（転機）：物販商材に出会う → 「なぜこれを選んだか」を丁寧に
   ↓
フェーズ4（実践）：実際にやって小さく稼ぐ → 「証拠」を見せる
   ↓
商材をアフィリ紹介（過程を見てきたフォロワーには刺さる）
```

## 逆算ロードマップ
### Phase 1：集客（〜フォロワー500人 / フェーズ1-2）
- 1日3投稿でストーリーを進める。失敗・停滞も正直に出して共感を最大化
- 同ジャンルへの絡みで横のつながりを作る

### Phase 2：転機（フェーズ3）
- 物販商材に出会う回を山場として演出（それまでの停滞があるほど映える）
- 「半信半疑だったけど、これを選んだ理由」を誠実に語る

### Phase 3：実践＆マネタイズ（フェーズ4）
- 実際にやった結果（初仕入れ・初出品・初売上）を一次情報で
- 成果とセットで商材をアフィリ紹介

## 集客導線
1. Threads投稿（ストーリー）でバズ→フォロワー獲得
2. 過程を追ってもらう→信頼蓄積
3. 転機〜実践でアフィリ商材を自然に紹介

## 逆算設計の原則
- 「フォロワーを増やしてからマネタイズ」ではなく、最初から物販という出口に向かう物語にしておく
- 購買意欲の高い「副業を探してる人」を集める＝高転換
