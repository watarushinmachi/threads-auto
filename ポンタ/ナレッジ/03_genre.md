# ポンタ ジャンル設計

## どんなジャンルか
- メインジャンル：**AIで0→1（まず月1万円）を作る副業ドキュメンタリー**
- 手段の軸：Threads × Claude Code（＋note）での自動化・収益化
- サブジャンル：AI活用ノウハウ、借金返済リアル

## 投稿配分
- AI活用術・0→1ノウハウ（Claude Code中心）：5割
- 借金返済リアル／「月1万円までの距離」報告：3割
- 実績・経過報告（ルナの成果含む）：2割

## ジャンルの選定理由
- AI系：低単価商品販売（1〜10万円）に適したジャンル
- 「Threads × Claude Code」は競合がほぼゼロのブルーオーシャン
- ドキュメンタリー要素：一次情報として価値が高い
- 借金返済＋「まず月1万円」：共感を呼びやすく、ファン化しやすい（たろう式の核）

## コンセプト（誰の・どんな悩み・どんな手段・どんな未来）
- 誰の：借金や将来不安を抱える20代後半〜30代の
- どんな悩み：お金がない・スキルがない・何から始めればいいかわからない
- どんな手段で：AI（Claude Code）を使ったThreads/note運用で
- どんな未来：**まずAIで月1万円**を作り、そこから自動化で月5万〜の仕組みへ

## ゴール商品
- **「Threads × Claude Code で稼ぐ完全ガイド」（note 5,000円）**
- 目標：100冊販売 = 50万円
- 内容イメージ：
  - Claude Codeの基本設定
  - ナレッジベースの作り方（8ファイル構成）
  - 6つのAIエージェントスキルの構築方法
  - 投稿自動生成→Discord承認→自動投稿の仕組み
  - ルナアカウントでの実証結果
- ポンタ自身の運用過程（＝「月1万円までの道のり」）がそのまま教材のネタになる
